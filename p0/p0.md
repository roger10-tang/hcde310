**What it provides** (1–2 sentences):

## Resource 2: Open-Meteo

**What it provides** (1–2 sentences):
provides weather forecast, temperature, rain probability, and wind speed. This data could help golfers plan when to play.

**Docs link:**
https://open-meteo.com/en/docs

**Access:** API key needed? Rate limits? Cost? (write "none" if none)
no API key needed. free for non-commercial use, up to 600 requests per minute, 5,000 per hour, 10,000 per day, and 300,000 per month.
