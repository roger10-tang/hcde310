I picked GolfCore from my P0 because I wanted to see how long a course plays from different tees. The API gives you course and tee details. A designer could use that data to help someone compare their options before playing a course for the first time.

I ran the example without an API key. To try it with a key, you can copy `r1/.env.example` to `r1/.env` and set `GOLFCORE_API_KEY`. I tested the run without a key. [GolfCore setup](https://www.golfcore.org/developers/)

The code asks GolfCore for Pebble Beach Golf Links. It reads the JSON response and loops through the layouts, then through the tees in each layout.

```python
import os
import requests
from dotenv import load_dotenv

load_dotenv()
key = os.getenv("GOLFCORE_API_KEY")
url = "https://api.golfcore.org/v1/courses/pebble-beach"
headers = {"User-Agent": "HCDE310 R1 course guide"}
if key is not None and key != "":
    headers["Authorization"] = f"Bearer {key}"

try:
    response = requests.get(url, headers=headers, timeout=10)
except requests.RequestException:
    response = None

if response is None:
    print("Request failed. Check your connection and try again.")
elif response.status_code != 200:
    print("Request failed:", response.status_code)
    print("Check the course slug, API key, or request allowance.")
else:
    data = response.json()
    print(data.get("name") or "Name unavailable")
    city = data.get("city") or "Unknown"
    region = data.get("region") or "Unknown"
    print(f"Location: {city}, {region}")
    print("Holes:", data.get("hole_count"))
    print("Par:", data.get("par_total"))
    print("Year built:", data.get("year_built") or "Unavailable")
    for layout in data.get("layouts") or []:
        print("Layout:", layout.get("name") or "Unnamed")
        for tee in layout.get("tees") or []:
            name = tee.get("name") or "Unnamed"
            gender = tee.get("gender") or "Unavailable"
            yards = tee.get("yards")
            if yards is None:
                yards = "Unavailable"
            print(f"  Tee: {name} | Rating category: {gender} | {yards} yards")
    print("Source: GolfCore", data.get("url") or "https://www.golfcore.org/")
```

The API had a `year_built` field, but its value was `None`. I used `or "Unavailable"` so the output would show something clearer. Gold also came back twice at 6,472 yards. The two entries had different rating categories, so I kept both.

I’d use this in a course preview for beginners. For example, someone could see that Blue plays 6,802 yards and Red plays 5,125 yards. I’d label M and F as rating categories so golfers can compare the tees without mistaking the labels for rules about who can use them.
